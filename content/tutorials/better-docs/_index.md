## 字体字号

基本要求: 

- 正文为5号字体, 中文字体用宋体, 英文字体使用Times New Roman. 图片中的字体要求与正文相同.
- 图片说明置于图片下方, 用宋体小5号. (借鉴于中国计算机学报)
- 表格说明至于表格上方, 用黑体小5号. (借鉴于中国计算机学报)
- 行距为单倍行距

标题要求 (借鉴于中国计算机学报):

- 题目字体为2号黑体
- 一级标题字体为4号黑体
- 二级标题字体为5号黑体
- 三级标题字体为5号宋体

## 描述的一致性

反例:

- 第一次描述为"256bit", 第二次描述为"256比特";
- 第一次描述为"哈希函数", 后面的描述却为"杂凑函数"或"摘要函数";
- 第一次描述为"哈希值", 第二次描述为"摘要值";

## 符号的一致性

反例:

- 第一次描述为$F$, 后面却出现了$\mathcal{F}$或$\mathbb{F}$等.
